# UniTools 🛠️

**UniTools** — это современный, быстрый и автономный (offline-first) набор инструментов разработчика на каждый день. Все утилиты разделены на изолированные модули, имеют независимые окна ввода/вывода, работают в красивом адаптивном интерфейсе с поддержкой тёмной/светлой темы и мультиязычности.

---

## 🌟 Возможности (Features)

### 1. Форматировщики (Formatters)
* **JSON Formatter** — валидация и форматирование JSON-объектов с мгновенной подсветкой синтаксических ошибок.
* **SQL Formatter (MS SQL)** — строгое форматирование и проверка синтаксиса диалекта **Transact-SQL / MS SQL** с помощью библиотеки `sqlglot`. Показывает точное местоположение ошибок (строку и колонку).
* **XML Formatter** — валидация и форматирование XML-документов, обнаружение несовпадающих тегов и некорректной разметки.

### 2. Кодировщики (Encoders)
* **Base64 Encoder / Decoder** — быстрое кодирование обычного текста в Base64 и обратно в один клик. Поддерживает мгновенную смену направления конвертации (Swap).

### 3. SQL Инструменты (SQL Tools)
* **SQL IN Builder** — преобразует список значений (ID), вставленных построчно, в готовую строку для SQL-запроса `IN ('val1','val2','val3')`. Автоматически экранирует одиночные кавычки/апострофы (например, `O'Brien` -> `'O''Brien'`).

### 4. Утилиты (Utilities)
* **URL Shortener** — сокращатель длинных ссылок с базой данных PostgreSQL и автоматическим 301/302-редиректом на оригинальный URL.

### 5. Системные настройки (Settings)
* **Язык интерфейса:** Русский, Украинский, Английский. Язык автоматически подстраивается под системные настройки вашего браузера при первом запуске.
* **Тема оформления:** Светлая и тёмная темы. Тема плавно переключается и сохраняется в локальном хранилище (`localStorage`).
* **Адаптивный дизайн:** Полностью приспособлен под мобильные телефоны и смартфоны.

## 🛠️ Стек технологий (Tech Stack)

* **Frontend:** React, TypeScript, Vite, Monaco Editor (движок от VS Code), Vanilla CSS (glassmorphism).
* **Backend:** FastAPI (Python 3.11), Uvicorn, Sqlglot (парсинг MS SQL), Sqlparse.
* **База данных:** PostgreSQL 15.
* **Окружение:** Docker & Docker Compose.

## 🚀 Установка и запуск (Installation & Setup)

Для локального запуска проекта вам понадобятся установленные **Docker** и **Docker Compose**.

### 1. Клонирование репозитория
```bash
git clone https://github.com/ordozz/UniTools.git
cd UniTools
```

### 2. Сборка и запуск контейнеров
Запустите Docker Compose в фоновом режиме:
```bash
docker-compose up -d --build
```
Эта команда скачает нужные образы, соберет фронтенд и бэкенд, настроит PostgreSQL и запустит три сервиса:
* **Frontend:** [http://localhost:5173](http://localhost:5173)
* **Backend API:** [http://localhost:8000](http://localhost:8000)
* **PostgreSQL:** порт `5432`

### 3. Перезапуск сервисов (при необходимости)
Если вы хотите принудительно перезапустить все контейнеры:
```bash
docker-compose restart
```
Или только фронтенд-сервис:
```bash
docker-compose restart frontend
```

## ⚙️ Разработка (Development)

Контейнеры настроены на монтирование локальных директорий (`volumes`), поэтому любые изменения в коде фронтенда (`frontend/src`) или бэкенда (`backend/app`) автоматически подхватываются с помощью Hot Reload (HMR для Vite и автоперезапуск FastAPI).
